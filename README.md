# Random Quote Generator

An interactive and responsive Random Quote Generator developed for the CodeAlpha App Development Internship.

## Features

- Random quote generation
- 30+ quotes
- Category filtering
- Search quotes
- Favorites
- Copy quote
- Share quote
- Quote history
- Statistics
- Dark/Light mode
- LocalStorage
- Responsive design
- Accessibility support

## Technologies

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Web Share API

## How to Run

Open `index.html` in a modern web browser.
